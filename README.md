# 法制史一图流

2027 法硕非法学 · 中国法制史单文件背诵应用。内容全部来自四份源材料（古代史一图流、近代史一图流、法制史纵向梳理计划·古代、法制史纵向梳理计划·近代）与众合龚成思讲义真题，逐句校对，不改写、不删减。

在线打开：https://kkdlm.github.io/fazhishi-yituliu/

## 功能

- **断代史 / 专题史双模式**：右上角切换。断代史按朝代看，专题史按六条纵向线（立法沿革、罪名与刑罚、司法制度、行政与监察、民事与婚姻继承、经济与土地）看，知识点不增不减，只换分类方式。
- **分类照源文件目录来**：古代 16 小节（立法指导思想、主要立法、主要法律形式演变、刑法原则演变、罪名演变、刑罚演变、司法制度演变、司法机构演变、监察制度演变、行政制度演变、官制演变、民事立法、经济立法、婚姻演变、继承演变、完结补充），近代按清末—南京国民政府（宪性文件、立法概况、民商立法、刑事立法、司法诉讼审判制度改革、司法体系变化）与革命根据地（宪性文件、土地立法、劳动立法、婚姻立法、刑事立法、司法制度）分开。
- **同一知识点融合**：四个文件里重复讲到的内容合并成一张卡片，按句去重，卡片内用源文件的概念小标题分段。
- **彩字还原**：源 PDF 中绿、蓝、红、紫、橙五色重点字全部保留，另有夜间模式配色。
- **五个板块**：总览、速览、背诵（抽背 / 挖空）、专题（时间轴、纵向专题、老龚点睛、一图流原页）、刷题。
- **题库**：仅讲义真题 405 道（单选 265 / 多选 140），没有自编题；解析逐项说明，错项讲清为什么错。
- **图片**：12 张老龚点睛原页（题目与解析里老师补充的内容）+ 6 张一图流原页总表，点击全屏、左右滑动看全。
- 纯单文件 HTML，无外部依赖，不联网可离线使用，手机优先（390px）。

## 使用

下载 `index.html` 直接用浏览器打开即可，无需联网、无需安装。
