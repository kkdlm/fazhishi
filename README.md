# 法制史一点通

2027 法硕非法学 · 中国法制史复习应用。手机优先的单页应用，打开即用，可离线。

**在线使用**：<https://kkdlm.github.io/fazhishi/>

（仓库与网址已从 `fazhishi-yituliu` 改名为 `fazhishi`，应用显示名仍是「法制史一点通」。旧链接 GitHub 会继续重定向，但建议用新地址。）

## 怎么用

- 浏览器直接打开上面的网址；手机可「添加到主屏幕」，像普通 App 一样使用。
- 五个板块：总览（断代史 / 专题史双模式）、速览（考点卡片）、背诵（抽背 · 挖空）、专题（时间轴 · 纵向专题 · 原页对照）、刷题。
- 搜索框支持关键词全量检索，展开卡片后正文里的关键词也会标出。

## 账号与同步

- **不注册也能用**：所有内容与功能全开，进度存在本机（换设备或清数据不同步）。
- **想跨设备接着背**：设置 → 账号与同步，用邮箱验证码登录（或邮箱 + 密码），登录后掌握、收藏、复习排期、笔记自动同步到云端。
- 云端只存学习进度与账号本身（邮箱、昵称、最后活跃时间与设备标识），不存任何身份信息，不用于推送。
- 换设备或意外丢掉本机数据时，也可以在设置里用「离线备份 / 备份码」导出或恢复。

## 说明

- 首次打开会缓存到本机，之后断网也能用；有新内容时页面顶部会询问是否现在更新。
- 内容供个人复习使用，欢迎报错：卡片底部有「报错」入口，会带上当前考点。

## 浏览器要求

iOS Safari / Android Chrome / 桌面 Chrome、Edge、Safari 均可。建议加桌面书签或主屏幕图标，避免每次都从网址进入。
