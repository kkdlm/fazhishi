# 法制史一点通

2027 法硕非法学 · 中国法制史复习应用。手机优先的单页应用，登录后使用，可加到主屏幕。

**在线使用**：<https://kkdlm.github.io/fazhishi/>

（仓库与网址已从 `fazhishi-yituliu` 改名为 `fazhishi`，应用显示名仍是「法制史一点通」。旧链接 GitHub 会继续重定向，但建议用新地址。）

## 怎么用

- 浏览器直接打开上面的网址；手机可「添加到主屏幕」，像普通 App 一样使用。
- **需要登录**：未登录时打开只会看到登录墙，总览、速览、背诵、专题、刷题全部不可用；注册免费（邮箱 + 验证码或密码）。
- 五个板块：总览（断代史 / 专题史双模式）、速览（考点卡片）、背诵（抽背 · 挖空）、专题（时间轴 · 纵向专题 · 原页对照）、刷题。
- 搜索框支持关键词全量检索，展开卡片后正文里的关键词也会标出。

## 免费 / 会员边界

登录即得免费账号，内容按「免费 / 会员」分层：

| 模块 | 免费账号 | 会员 |
| --- | --- | --- |
| 速览 | 专题史整合版 | 全部（含断代史精讲全文） |
| 专题 | 一图流原页 | 全部（时间轴、纵向专题、背诵一本通对照） |
| 背诵 | 每天 5 张卡（服务端按账号计数，次日 0 点恢复） | 不限量 |
| 刷题 / 挖空 | 关闭 | 打开 |

- 免费额度按 **账号** 在服务端计数：清缓存、换浏览器、换设备都不会重置；同一张卡当天复习不重复占用额度。
- 已看过的卡当天仍可继续复习，不因额度用尽而锁死。
- 想不限量：用「卡密」兑换，或走「邀请有礼」——邀请人每成功一次加 7 天、被邀请人加 3 天（天数可在后台配置）。

## 账号与同步

- 登录后掌握、收藏、复习排期、笔记自动同步到云端，换设备接着背。
- 云端只存学习进度与账号本身（邮箱、昵称、最后活跃时间与设备标识），不存任何身份信息，不用于推送。
- 同一账号最多 3 台设备同时活跃（45 天内有过访问才算一台），超出会在新设备上提示解绑旧设备。
- 退出登录后回到登录墙，再登录即恢复云端进度。

## 说明

- 首次打开会把全书内容缓存到本机，之后断网也能用；有新内容时页面中央会提示是否现在更新。
- 会员到期后自动回到免费额度；后台调整的天数与免费上限，App 下次刷新即生效（不需要重新下载）。
- 内容供个人复习使用，欢迎报错：卡片底部有「报错」入口，会带上当前考点。

## 浏览器要求

iOS Safari / Android Chrome / 桌面 Chrome、Edge、Safari 均可。建议加桌面书签或主屏幕图标，避免每次都从网址进入。
