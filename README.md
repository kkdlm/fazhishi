# 法制史一图流

2027 法硕非法学·中国法制史单文件背诵应用，全部内容来自四份源材料（古代史一图流、近代史一图流、纵向梳理古代、纵向梳理近代）与众合龚成思讲义真题。

## 功能

- **断代史 / 专题史双模式**：右上角切换，仅改变总览与速览的分类方式，知识点不增不减
- **彩字还原**：源 PDF 中绿、蓝、红、紫、橙五色重点字全部保留，支持夜间模式
- **五个板块**：总览、速览、背诵（抽背/挖空）、专题（时间轴、纵向专题、老龚点睛、一图流原页）、刷题
- **题库**：仅含讲义真题 405 道（单选 265 / 多选 140），无 AI 自编题
- 纯单文件 HTML，无外部依赖，手机优先（390px）

## 使用

直接打开 `index.html` 即可，无需联网、无需安装。

启用 GitHub Pages 后可在线访问：仓库 Settings → Pages → Source 选择 `main` 分支根目录。
